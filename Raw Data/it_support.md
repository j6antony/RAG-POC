# IT Support Guide

## Getting Help

Employees can contact IT support through the internal help desk portal.

For urgent issues that prevent an employee from working, the request should be marked as high priority.

## Password Problems

Employees who forget their password should use the self-service password reset tool.

If the reset tool is unavailable, IT support can verify the employee's identity and assist with account recovery.

## Multi-Factor Authentication

Employees who replace or lose their authentication device should contact IT to reset their multi-factor authentication enrollment.

Authentication codes should never be shared with IT staff or coworkers.

## VPN Issues

Employees who cannot connect to the corporate VPN should first confirm that they have an internet connection and restart the VPN application.

If the problem continues, the employee should submit a help desk request including any visible error message.

## Lost Devices

A lost or stolen company laptop or phone should be reported immediately.

Employees should contact IT so the device can be locked or remotely wiped if necessary.

The incident should also be reported to the employee's manager.

## Software Requests

Employees should not install unapproved software on company devices.

Requests for new software should be submitted through the help desk portal for security and licensing review.
